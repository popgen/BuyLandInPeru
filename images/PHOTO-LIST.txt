PHOTOS — Buy Land In Peru
=========================
How it works now
- Your original photos stay here in /images exactly as you named them (underscores are fine).
- The website uses smaller, web-sized copies in /images/web (made by Claude). Don't edit those by hand.
- To add or replace a photo: drop it here and ask Claude to "process the new photos". Claude will
  make the web copy and put it on the page.
- The "construction progress" folder feeds the Build progress page (progress.html), in date order.
- Tip: once the site is live, you can move the large originals out of the site folder to keep the
  GitHub repo small. The website only needs /images/web.
